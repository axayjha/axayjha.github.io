<h2>Getting started with MASM 8086 assembly</h2>

<p>Why suddenly 8086 assembly using MASM? Well, partly because I love exploring random legacy system programming and partly because I stumbled upon this book called "C using Assembly Language" by Steven Holzner (1989). Author has used Quick C and Microsoft Micro Assembler to demonstrate use cases. So here I am, experimenting with stuffs.</p>

<h3>Setup</h3>

<p>To get started with MASM, we need to have DOSBOX (an IBM PC compatible DOS emulator) and MASM 8086 assembler files to go along with it.</p>

<p>I use a Mac, so my instructions will be for MacOS. However, these steps are same for the most part for other platforms too, as our tool of choice, DOSBOX, is available for other OSes too.</p>

<p>Download DOSBOX from <a href="http://www.dosbox.com">here</a>. Download 8086 assembler from <a href="http://www.mediafire.com/file/mm7cjztce9efj4w/8086.zip">here</a>.</p>

<p>Copy DOSBOX to Applications from the disk image file. Then make a folder named "dosbox" in your home directory. Extract 8086.zip files to ~/dosbox.</p>

<h3>Running DOSBOX</h3>

<p>Now start DOSBOX. You should see the prompt to be <code>Z:\></code></p>

<p>Type "mount c ~/dosbox/8086":</p>

<pre><code>Z:\> mount c ~/dosbox/8086</code></pre>

<p>Then type "c:" to change drive:</p>

<pre><code>Z:\> C:
C:\></code></pre>

<p>Now you are ready to go. You can use the "edit" utility to create and edit new asm files. For example: <code>edit hello.asm</code></p>

<p>Once you are done writing the code (you can try the code snippet from below), you need to assemble and link before executing:</p>

<pre><code>masm hello.asm
link hello
hello.exe</code></pre>

<p>Keep pressing Enter to bypass the prompts and to use default values for other filenames.</p>

<h3>The assembly code</h3>

<p>MASM programs usually contain two segments: CODE and DATA. The CODE segment contains the opcodes. The DATA segment contains the variables.</p>

<p>In this code, we are going to define a variable named MSG which will store the string to be printed. DB (Define Byte) is a directive that is used to reserve byte(s) of memory locations in available memory. "$" at the end of the variable declaration is used to signify termination of the string.</p>

<p>In the code segment, the following two statements (line 12, 13) are used to initialise the DATA segment:</p>

<pre><code>MOV AX, DATA
MOV DS, AX</code></pre>

<p>These two statements must be used in all MASM codes.</p>

<p>Lines 15 to 17 are used to print the string. To output a string in 8086 assembly, we load the address of a '$'-terminated string into DX and then call the interrupt with function code 09h in AH. MS-DOS provides many interrupt services through INT 21H. Function code 09h is just one of them (i.e., to output a string).</p>

<p>Lines 20, 21 are used to exit the program. In MS-DOS on 8086, we save the return code for a program in the AL register. Then we call the interrupt with function code 4Ch in AH. In line 20 we are directly moving 4C00h into AX, signifying normal exit.</p>
