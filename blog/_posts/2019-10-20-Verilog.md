<h2>Running Verilog code on Linux/Mac</h2>

<p>Step by step instructions to setup and install tools to run and visualize Verilog HDL designs on *nix systems.</p>

<h2>Install</h2>

<p>Note: The steps below have been tested on Ubuntu 16.04 and MacOS 10.14.</p>

<h3>1. Compile from source on Linux/Mac or in Cygwin on Windows</h3>

<p>You will need <code>make</code>, <code>autoconf</code>, <code>gcc</code>, <code>g++</code>, <code>flex</code>, <code>bison</code> to compile (and maybe more depending on your system).</p>

<p>Clone the git repo:</p>

<pre><code>$ git clone https://github.com/steveicarus/iverilog.git</code></pre>

<p>cd into the directory:</p>

<pre><code>$ cd iverilog</code></pre>

<p>Build configuration files:</p>

<pre><code>$ sh autoconf.sh</code></pre>

<p>If this gives <code>autoconf.sh: line 10: autoconf: command not found</code>, then install the needed packages.</p>

<p>On MacOS:</p>

<pre><code>$ brew install autoconf automake libtool</code></pre>

<p>On Ubuntu:</p>

<pre><code>$ sudo apt-get install autoconf</code></pre>

<p>A successful run should output:</p>

<pre><code>Autoconf in root...
Precompiling lexor_keyword.gperf
Precompiling vhdlpp/lexor_keyword.gperf</code></pre>

<p>Configure:</p>

<pre><code>$ ./configure                        # for default settings - installs to /usr/local/bin
$ ./configure --prefix=&lt;your directory&gt;  # installs to specific directory provided</code></pre>

<p>Compile the source:</p>

<pre><code>$ make</code></pre>

<p>This command will require gcc, g++, bison and flex. You can install them using Homebrew or apt-get on Mac and Ubuntu respectively.</p>

<p>Get into superuser mode and install:</p>

<pre><code>$ sudo su
$ make install</code></pre>

<h3>2. Install on MacOS using Homebrew</h3>

<pre><code>$ brew install icarus-verilog</code></pre>

<p>(Optional) Install iverilog waveform dumpfile viewer - <code>gtkwave</code>:</p>

<pre><code>$ sudo port -v install gtkwave</code></pre>

<p>If gtkwave installation gives <code>Error: Failed to configure gtk-osx-application-common-gtk2: gtk2 +quartz not installed.</code>, do:</p>

<pre><code>$ sudo port install gtk2 +quartz</code></pre>

<h3>3. Install on Ubuntu using aptitude</h3>

<pre><code>$ sudo add-apt-repository ppa:team-electronics/ppa
$ sudo apt-get update
$ sudo apt-get install verilog
$ sudo apt-get install gtkwave</code></pre>

<p>Note: Windows binaries are available at <a href="http://bleyer.org/icarus/">http://bleyer.org/icarus/</a>. For more details on installation, visit <a href="https://iverilog.fandom.com/wiki/Installation_Guide">https://iverilog.fandom.com/wiki/Installation_Guide</a>.</p>

<h2>Run</h2>

<h3>Example 1: Hello World</h3>

<p>Save this Verilog code as <code>hello.v</code>:</p>

<script src="https://gist.github.com/axayjha/53ae51dd5f4199b5cecab5f2445fe8bb.js"></script>

<p>Compile using:</p>

<pre><code>$ iverilog -o hello hello.v</code></pre>

<p>Run the compiled executable:</p>

<pre><code>$ vvp hello
Hello World!</code></pre>

<h3>Example 2: ALU</h3>

<p>Save the code below as <code>alu.v</code>:</p>

<script src="https://gist.github.com/axayjha/f82d99b905303e1ede13b03f672fb5cb.js"></script>

<p>Save the code below as <code>alu_tb.v</code>:</p>

<script src="https://gist.github.com/axayjha/4e3fdba295c860bc7018267371eb421a.js"></script>

<p>Compile and run:</p>

<pre><code>$ iverilog -o alu alu_tb.v alu.v
$ vvp alu +a=3 +b=2 +s=0
y= 5</code></pre>

<p>Here <code>s=0</code> selects the addition operation which is performed over <code>a=3</code> and <code>b=2</code>. So the output y is 3+2=5.</p>
